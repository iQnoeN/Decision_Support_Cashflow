# AI-Based Micro-Business Cashflow Management System

## Overview

This project is a Final Year Computer Science research project focused on predicting short-term liquidity risk for Micro, Small, and Medium Enterprises (MSMEs) using Machine Learning.

The system forecasts future cashflow based on historical transaction data and estimates liquidity risk to provide actionable financial recommendations for business owners.

---

## Research Topic

**Short-Term Liquidity Risk Prediction Based on Cashflow Analysis Using Machine Learning**

---

## Objectives

- Forecast short-term cashflow (7–30 days)
- Estimate liquidity risk
- Generate financial recommendations
- Provide an interactive web dashboard
- Support decision making for MSMEs
